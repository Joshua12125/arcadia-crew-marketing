    Google Business Profile

    Where you sit in the local map pack.

    Straight answer: Google doesn't expose local-pack position through any official API — that's deliberate, to stop exactly this kind of automated checking. Tools that do this (LocalFalcon, BrightLocal, and similar) all run on paid third-party search-data APIs that simulate searches from multiple points around a location. Same two paths as ranking above:

    Self-serve

    Bring your own API key

    If you hold a local-search API key (SerpApi's Google Maps engine, DataForSEO, etc.), paste it with your business name and target keyword. The key stays in this browser tab only.

    Not configured yet — see the note above.

    Managed

    We set it up for you

    On paid engagements, Arcadia Crew Marketing runs proper grid-based local rank tracking — multiple simulated search points around your service area, tracked over time — as part of local SEO work.
